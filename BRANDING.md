# BenchForge visual identity

## Purpose

Answer "is it slower, or just noise?" with recorded samples and a stated test.

## Design system

- Maker's mark: by OBEOS.
- Project name: BenchForge.
- Accent: `#2dd4bf` (performance teal).
- Canvas: `#0c1220`; primary text: `#f3f5fa`; secondary text: `#99a7bc`.
- Symbol: three rising bars crossed by a dashed threshold line.
- Banner: `assets/brand/github-banner.svg`, 1200 × 400, with a self-contained dark background for light and dark GitHub themes.
- Shared with the other OBEOS projects: typography, spacing, grid, footer line and the README section order. Each project keeps its own accent colour and symbol; Sentinel's cyan shield is the reference, Blackbox is amber, Casefile violet, Dockyard green, RestorePoint coral, PacketStory pink and ProofBoard blue.
- SVG has no script, external fonts, linked images or animation. Keep title and description accessible.

## Editorial rules

Explain the working product before the roadmap. Keep setup, limits and evidence visible. Do not add unverified release, security, performance, platform-support, test-count or AI capability claims; link a test or a recorded evidence file instead. Real timings are labelled with the machine they came from.

## Maintenance

Edit the SVG as text. Keep the name and descriptor inside the left text area (x=48 through x=860); reserve the right area for the symbol. Preserve the viewBox. `assets/social-preview.png` is the banner on a 1280 × 640 canvas, for GitHub's social preview setting.

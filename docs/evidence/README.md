# Evidence

Recorded outputs behind the claims in the README.

| File | What it is | Reproduces exactly? |
|---|---|---|
| `test-run.txt` | The full test run with coverage (Linux, Python 3.13) | No: timing line varies |
| `acceptance-transcript.txt` | `show` and `compare` on the synthetic baseline and candidate, exit codes included | Yes: `python examples/acceptance.py --out docs/evidence`, checked by a test |
| `compare.md`, `compare.html`, `compare.json` | The comparison in each report format | Yes, same command |
| `real-run.txt` | A real run of the demo suite on one machine | No: timings are machine-specific, labelled as such |

The synthetic baseline and candidate (`examples/demo/baseline.json`, `candidate.json`) are made up: seeded log-normal noise around chosen medians, generated by `examples/make_synthetic.py` and checked against the committed files by a test. They show how verdicts behave, not how any real project performs. Nothing here was recorded on Windows or macOS; CI runs the tests on Windows.
